Generador de archivos grandes

Listo.
En Safari se usa el almacenamiento de archivos del navegador (OPFS) para escribir el archivo por bloques y después descargarlo. No se crea un string gigantesco en memoria.
Para 5 GB necesitas tener al menos ese espacio libre y Safari puede aplicar límites de almacenamiento del sitio. Modo de navegación privada puede no ser compatible con este método.
